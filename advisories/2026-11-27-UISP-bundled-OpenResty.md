# UISP — Bundled nginx/OpenResty and the November 2026 nginx CVEs (NOT CONFIRMED BY UBIQUITI)

> **NOT CONFIRMED BY UBIQUITI.** The web server versions below come from the public metadata of Ubiquiti's container image `ubnt/unms-nginx` on Docker Hub, not from a Ubiquiti advisory. Whether each Docker Hub tag matches the UISP release with the same number, and whether a given UISP configuration exposes each flaw, has not been confirmed by Ubiquiti. This advisory has been reported to Ubiquiti and will be updated with their answer.

| Field | Details |
|---|---|
| **ID** | MITS-2026-0010 |
| **Product** | UISP (Ubiquiti), through the nginx or OpenResty (an nginx distribution) bundled in its `ubnt/unms-nginx` container image. |
| **Summary** | The November 2026 nginx update (nginx 1.31.9 and 1.30.7) fixes ten CVEs, and a later update (1.31.10 and 1.30.8) fixes one more. According to the metadata of Ubiquiti's public `ubnt/unms-nginx` image, UISP 3.1.x tags bundle OpenResty and UISP 3.2.x tags bundle nginx. Tags 3.1.73 and 3.2.8 are in the affected range of nine of the ten CVEs; tags 3.1.74 and 3.2.9 bundle versions that fix all ten. All four are in the affected range of CVE-2026-132779. **Not confirmed by Ubiquiti.** |
| **Bundled web server (per image metadata)** | Source: metadata of Ubiquiti's public image [ubnt/unms-nginx on Docker Hub](https://hub.docker.com/r/ubnt/unms-nginx) (tags 3.1.73, 3.1.74, 3.2.8, 3.2.9; amd64; read 2026-11-27). **3.1.73** (also tagged `latest`; image created 2026-10-22): OpenResty 1.29.2.5, which is based on nginx 1.29.2 ([OpenResty 1.29.2.x changelog](https://openresty.org/en/changelog-1029002.html)): affected by nine of the ten November CVEs (not CVE-2026-120993) and by CVE-2026-132779. **3.1.74** (2026-11-26): OpenResty 1.31.9.1: fixes the ten; affected by CVE-2026-132779. **3.2.8** (2026-11-12): nginx 1.30.6: affected by nine of the ten (not CVE-2026-120993) and by CVE-2026-132779. **3.2.9** (2026-11-23): nginx 1.30.7: fixes the ten; affected by CVE-2026-132779. Not verified: that each tag is the UISP release with the same number, and whether the 3.2 tags are a stable or a pre-release channel. |
| **Related CVEs (November nginx update)** | Affected nginx Open Source versions per nginx.org; severity from F5 (CNA). [CVE-2026-123007](2026-11-26-CVE-2026-123007.md) HTTP/2, 1.9.5–1.31.8, Critical · [CVE-2026-123633](2026-11-26-CVE-2026-123633.md) HTTP/2, 1.19.7–1.31.8, Critical · [CVE-2026-123634](2026-11-26-CVE-2026-123634.md) resolver, 0.6.18–1.31.8, Critical · [CVE-2026-121810](2026-11-26-CVE-2026-121810.md) HTTP/3, 1.25.0–1.31.8, Critical · [CVE-2026-113425](2026-11-26-CVE-2026-113425.md) mail proxy, 0.5.33–1.31.8, Critical · [CVE-2026-118899](2026-11-27-CVE-2026-118899.md) TLS 1.3 request body, 1.13.0–1.31.8, High · [CVE-2026-125283](2026-11-27-CVE-2026-125283.md) alias with try_files, 0.9.6–1.31.8, Medium · [CVE-2026-120967](2026-11-27-CVE-2026-120967.md) stream client certificates, 1.25.5–1.31.8, Medium · [CVE-2026-123640](2026-11-27-CVE-2026-123640.md) stream ssl_preread, 1.15.2–1.31.8, Medium · [CVE-2026-120993](2026-11-27-CVE-2026-120993.md) PROXY protocol v2, **1.31.4–1.31.8 only**, Medium. |
| **Related CVE (later nginx update)** | [CVE-2026-132779](2026-11-26-CVE-2026-132779.md) TLS 1.3 early data, 1.21.4–1.31.9, Medium. |
| **Fixed versions** | nginx 1.30.7 and 1.31.9 fix the ten CVEs of the November nginx update (1.31.9 only for CVE-2026-120993; source: [nginx.org security advisories](https://nginx.org/en/security_advisories.html)). **OpenResty 1.31.9.1** (2026-11-23) upgrades its nginx core from 1.31.8 to 1.31.9 and lists fixes for the ten (source: [OpenResty 1.31.9.x changelog](https://openresty.org/en/changelog-1031009.html)). |
| **Not yet fixed** | **CVE-2026-132779** is fixed in nginx 1.30.8 and 1.31.10 (source: nginx.org). None of the four `ubnt/unms-nginx` tags above bundles one of those versions. No OpenResty release with this fix was found: the latest release on the [OpenResty download page](https://openresty.org/en/download.html) is 1.31.9.1, and its changelog does not mention CVE-2026-132779 (checked 2026-11-27). |
| **Ubiquiti status** | No UISP advisory from Ubiquiti about these CVEs is cited here. Ubiquiti's [release notes](https://community.ui.com/releases) list UISP Application 3.1.73 (2026-11-13, GA) as the latest UISP Application release; no release notes for 3.1.74, 3.2.8 or 3.2.9 were found (checked 2026-11-27). |
| **Recommended action** | Update UISP to a release whose image ships nginx 1.30.7 or later, nginx 1.31.9 or later, or OpenResty 1.31.9.1 or later (per image metadata: 3.1.74 or 3.2.9), once Ubiquiti releases it for your channel. CVE-2026-132779 remains unfixed in all of them. |
| **Note (Master IT Support)** | General hardening, not a vendor recommendation: (1) limit access to the UISP web interface to trusted management networks; (2) disable HTTP/2 where it is not needed (see [CVE-2026-123007](2026-11-26-CVE-2026-123007.md) for the nginx directives). UISP manages its own nginx configuration: a manual change may be overwritten by a UISP update and is not supported by Ubiquiti, so check with Ubiquiti before changing it. |
